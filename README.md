# سجل الحضور والغياب
فكرة وتصميم — نعيمه الرشيدي

- index.html: أول ما يُفتح يسأل «طالبة أم أستاذة؟». الطالبة تنتقل لصفحتها، والأستاذة لتطبيقها.
- excuse.html: صفحة الطالبات (اختيار الأستاذة ثم الشعبة، الجدول، القاعات، الإعلانات، وإرسال العذر)
- setup.sql: إعداد قاعدة البيانات في Supabase (مرة واحدة)
- config.js: ضعي فيه رابط مشروع Supabase ومفتاح anon

## بدون إنترنت
- الأستاذة: التحضير والإعداد والسجلات تعمل بدون نت وتُحفظ على الجوال، وتُرفع تلقائيًا عند الاتصال. قرارات الأعذار والإعلانات تُرسل تلقائيًا عند عودة النت.
- الطالبة: الجدول والقاعات والإعلانات تظهر من آخر نسخة محفوظة. العذر المرسل بدون نت يُحفظ مؤقتًا ويُرسل وحده عند الاتصال ثم يُحذف من جوالها.

## أين تُحفظ الأعذار؟
في قاعدة بيانات Supabase فقط (مع المرفقات). لا تُخزَّن على جوال الأستاذة.
